# Gitora 0.1.12

Дата релиза: 24.07.2026

## Главное в обновлении

Gitora стала безопаснее и лучше синхронизируется с GitHub. В версии 0.1.12 вошли:

- защищённая работа MCP через локальный Electron-мост;
- безопасное хранение GitHub-сессии без передачи токена MCP;
- дополнительные проверки URL, SHA, Git refs и номеров PR/issue;
- поддержка веток с именами вроде `feature/my-change`;
- настройка лимита загружаемых коммитов;
- полная синхронизация списка GitHub-репозиториев из настроек: новые репозитории добавляются, удалённые исчезают;
- обновление веток, коммитов и графа текущего репозитория;
- защита README от устаревших ответов при смене ветки;
- исправление некорректных запросов и подготовка архитектуры к дальнейшим улучшениям;
- installer с понятным именем `Gitora 0.1.12.exe`.

## Проверки релиза

- TypeScript проверен без ошибок;
- автоматические тесты проходят;
- production build проходит;
- Electron smoke-проверка проходит;
- installer собран через electron-builder.
