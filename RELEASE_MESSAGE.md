# Что нового в Gitora 0.2

Gitora стала удобнее, безопаснее и надёжнее при работе с GitHub и ИИ.

Теперь приложение:

- синхронизирует список репозиториев с GitHub;
- добавляет новые и убирает удалённые репозитории;
- обновляет ветки, коммиты и граф текущего проекта;
- надёжнее работает с MCP и GitHub-сессией;
- проверяет входные данные и защищает загрузки;
- позволяет выбрать лимит загружаемых коммитов.
- поддерживает первый commit в пустом репозитории;
- показывает понятное состояние MCP-подключения и автоматически ждёт ответ клиента;
- диагностирует GitHub permissions и ошибки записи;
- делает поиск коммитов переходом к нужному результату;
- объединяет настройки MCP в один понятный экран.

Спасибо, что используете Gitora!
