# Правила агента

## Визуализация объяснений

При объяснении чего-либо пользователю всегда используй навык `Visualize`, если информацию можно сделать понятнее с помощью визуализации.

Используй `Visualize` для схем, архитектуры, процессов, связей между компонентами, потоков данных, структуры проекта, сравнений и других сложных объяснений.

Цель: не ограничиваться сухим текстом — по возможности показывать информацию визуально, чтобы объяснения были понятнее и нагляднее.
